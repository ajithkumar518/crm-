1 Email to Lead Extraction

Configured & Tested

Polls a Microsoft 365 mailbox via the Graph API, reads unread emails, classifies them, extracts lead information, and creates leads automatically.

Env vars: MS_GRAPH_CLIENT_ID MS_GRAPH_CLIENT_SECRET MS_GRAPH_TENANT_ID MS_GRAPH_MAILBOX CRON_SECRET INTERNAL_COMPANY_ID INBOUND_MAX_MESSAGES_PER_RUN
Files: lib/inbound-email-service.ts, lib/email-classification.ts, lib/email-extractor.ts, lib/leadWorkflow.ts, app/api/cron/email-poll/route.ts, instrumentation.ts
  • Trigger: POST /api/cron/email-poll with CRON_SECRET, or automatic 2-minute polling in production.
  • Output: New Lead with code, assignment, SLA deadline, and notification.

2 Quotation Send

Configured

Generates a branded quotation PDF and emails it to the customer or contact. Updates the quotation status and creates a follow-up task.

Env vars: SMTP_HOST SMTP_PORT SMTP_USER SMTP_PASS SMTP_FROM NEXT_PUBLIC_APP_URL
Files: app/api/quotations/[id]/send/route.ts, lib/email.ts, lib/generateSukiQuotationPdf.ts
  • Trigger: Send button on the quotation detail page.
  • Status transition: Draft / Approved / UnderReview → Quotation Sent.

3 Proforma Invoice

Configured

Two related flows: (A) email a proforma PDF to the customer, and (B) convert an approved proforma invoice into a sales order.

Env vars: SMTP_HOST SMTP_PORT SMTP_USER SMTP_PASS SMTP_FROM
Files: app/api/proforma-invoices/[id]/send/route.ts, app/api/proforma-invoices/[id]/sales-order/route.ts, lib/email.ts
  • Send trigger: Send button on proforma detail page. Status must be Draft or Sent.
  • SO creation trigger: Create Sales Order button on approved proforma. Computes totals, tax, and saves the order.

4 Product Pull from ERP

Configured

Connects directly to the ERP SQL Server database and MERGEs product master data, stock levels, prices, categories, and grades into the CRM Product table.

Env vars: ERP_ADMIN_PASSWORD
Files: scripts/erp-sync-poller.mjs, __run_erp_sync_now.mjs, scripts/erp-product-sync.sql, scripts/erp-category-sync.sql
  • Schedule: Products every 2 minutes, categories every 24 hours.
  • Source: ERPDb_SHAHNAZ_CHE.dbo.PRODUCT and daily_trans on 192.168.1.160:1433.

5 Sales Order Push to ERP

Configured & Tested

Builds a flat JSON array payload for the ERP and POSTs it to the SUKI ERP sales order endpoint. Updates sync status and stores the ERP reference.

Env vars: SUKI_ERP_API_URL SUKI_ERP_API_KEY
Files: app/api/sales-orders/[id]/sync-erp/route.ts
  • Trigger: Sync to ERP button on the sales order detail page.
  • Endpoint: {SUKI_ERP_API_URL}/saleOrder
  • Format: Flat JSON array containing item-level and order-level fields.

6 Purchase Order Push to ERP

Configured

Similar to the sales order flow but for purchase orders. Sends an approved PO payload to the ERP.

Env vars: SUKI_ERP_API_URL SUKI_ERP_API_KEY
Files: app/api/purchase-orders/[id]/sync-erp/route.ts
  • Trigger: Sync to ERP button on the purchase order detail page.
  • Status guard: PO must be Approved.

7 Lead Ingestion API

Configured

Exposes a secure REST endpoint so external websites or landing pages can create leads in the CRM.

Env vars: LEADS_API_KEY INTERNAL_COMPANY_ID
Files: app/api/leads/route.ts, lib/leadWorkflow.ts
  • Endpoint: POST /api/leads
  • Auth: Header x-api-key matching LEADS_API_KEY or systemConfig leads_api_key.

8 Currency Exchange Rates

Configured

Fetches live INR/USD/EUR exchange rates, caches them in the database, and converts/format amounts for display.

Env vars: EXCHANGE_RATE_API_KEY
Files: lib/currency.ts
  • Primary source: exchangerate-api.com
  • Fallback source: open.er-api.com (free, no key)
  • Cache: ExchangeRate table, refreshed every 24 hours.

9 Cron / Scheduled Jobs

Configured

Protected HTTP endpoints designed to be called by an external scheduler such as Vercel Cron, Azure Functions, or a local cron job.

Env vars: CRON_SECRET CRON_API_KEY
Files: app/api/cron/email-poll/route.ts, app/api/cron/nightly-batch/route.ts, app/api/cron/proposals/route.ts, app/api/cron/subscriptions/route.ts, app/api/quotations/expire-stale/route.ts
  • Email poller: Also auto-starts in production via instrumentation.ts every 2 minutes.
  • Other jobs: Expire stale proposals, nightly account aging, birthday reminders, PO auto-hold, stale quotation expiry.
