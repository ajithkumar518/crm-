# Dashboard

The Dashboard is the landing page of the CRM and the first screen every user sees after logging in. It provides a consolidated, at-a-glance view of sales performance, pipeline health, lead flow, quotation status, follow-up activity, and system alerts — all in one scrollable page.

> **Who sees this:** All roles except Service Engineers. Service Engineers are automatically redirected to the My Visits page in the Service module and do not see this dashboard.

---

## Pages in this Module

| # | Page | Route | Purpose |
|---|------|-------|---------|
| 1 | [Main Dashboard](#1-main-dashboard) | `/dashboard` | Consolidated admin view with KPIs, charts, and widgets |
| 2 | [CRM Dashboard](#2-crm-dashboard) | `/dashboard/crm` | SUKI-focused CRM metrics (leads, quotations, conversions) |
| 3 | [Manager Dashboard](#3-manager-dashboard) | `/dashboard/manager` | Sales manager view with team performance and analytics |
| 4 | [SUKI Dashboard](#4-suki-dashboard) | `/dashboard/suki` | Lightweight SUKI Steel CRM dashboard with KPIs and charts |

The **Main Dashboard** (`/dashboard`) is the default landing page and the most comprehensive. The other three routes (`/dashboard/crm`, `/dashboard/manager`, `/dashboard/suki`) are alternative, focused views that can be navigated to directly. Most users will only interact with the Main Dashboard.

## 1. Main Dashboard

**Route:** `/dashboard`

This is the default landing page. It combines sales, pipeline, follow-up, and SUKI CRM metrics into a single scrollable view.

### Page Header

The page header shows the title **"Dashboards Overview"** with the subtitle *"Master consolidated view of sales, pipeline, and module activity"*. On the right side of the header is a **Date Range** dropdown that filters the sales analytics data.

[SCREENSHOT NEEDED: Main Dashboard — full page header with title "Dashboards Overview" and the Date Range dropdown visible on the right]

#### Date Range Filter

A dropdown selector in the top-right corner that controls the time window for sales analytics charts and KPIs.

| Option | Effect |
|--------|--------|
| **All Time** (default) | No date filter — includes all historical data |
| **Last 30 Days** | Only counts records created in the past 30 days |
| **Last 3 Months** | Only counts records created in the past 3 months |
| **Last 6 Months** | Only counts records created in the past 6 months |

> **Note:** The date range filter only affects the **Sales Analytics** data (KPIs, funnel, agent leaderboard, revenue trend). The SUKI KPI strip and CRM metrics are not affected by this filter — they show all-time or current-month counts.

**How to use:** Click the dropdown and select a range. The page automatically reloads data for the new range.

- A **large numeric value** with a count-up animation
- A **trend badge** ("Good" with green up-arrow, or "Action" with red down-arrow)
- A **trend description** (e.g., "All time", "This month", "Needs attention")
- A **colored icon** in the top-right corner

[SCREENSHOT NEEDED: KPI Strip — the row of 10 KPI cards at the top of the dashboard showing Total Leads, New Leads, Quotations Sent, etc.]

#### KPI Cards (left to right)

| # | KPI | What it shows | Trend logic |
|---|-----|---------------|-------------|
| 1 | **Total Leads** | All-time total lead count | "Good" if > 0 |
| 2 | **New Leads** | Leads created this month | "Good" if > 0 |
| 3 | **Quotations Sent** | Quotations with status "Quotation Sent" (awaiting customer response) | "Good" if > 0 |
| 4 | **Follow-up Pending** | Quotations with status "Follow-up" | "Good" if 0 (no pending = good) |
| 5 | **Accepted** | Quotations with status "Accepted" (won quotes) | "Good" if > 0 |
| 6 | **Rejected** | Quotations with status "Rejected" (lost quotes) | "Good" if 0 (no rejections = good) |
| 7 | **Converted Customers** | Quotations with status "Converted to Customer" | "Good" if > 0 |
| 8 | **Supplier Rate Checking** | Quotations pending supplier rate verification | "Good" if 0 (none pending = good) |
| 9 | **Material Not Available** | Quotations blocked due to material unavailability | "Good" if 0 |
| 10 | **No Stock** | Quotations blocked due to out-of-stock items | "Good" if 0 |

> **Tip:** Cards 4, 6, 8, 9, and 10 use inverted logic — a value of 0 shows "Good" (green), because having zero pending/rejected/blocked items is the desired state.

### User Actions on the Main Dashboard

| Action | How to perform | Effect |
|--------|----------------|--------|
| **Change date range** | Click the "Date Range" dropdown in the header → select an option | Reloads sales analytics data for the selected period |
| **View lead details** | Click "View All →" on the Recent Leads widget | Opens the Leads module |
| **Hover funnel bars** | Mouse over a bar in the Pipeline Stages chart | Shows a tooltip with the exact lead count for that stage |
| **Hover revenue bars** | Mouse over a bar in the Sales Analytics chart | Shows a tooltip with month and revenue value |
| **Hover doughnut segments** | Mouse over a segment in Lead Source or Quotation Status charts | Shows tooltip with source name, count, and percentage |
| **Scroll the page** | Use mouse wheel or scroll bar | Reveals all sections (the dashboard is a long scrollable page) |

> **Note:** The dashboard is primarily a **read-only** view. It does not have inline editing, create, or delete actions. To act on any data shown (e.g., call a lead, close a deal, send a quotation), navigate to the relevant module using the sidebar.

## Natural Workflow for a New User

1. **Log in** → You land on the Main Dashboard (`/dashboard`)
2. **Scan the KPI strip** → Get a quick sense of lead volume, quotation status, and conversion health
3. **Review the SUKI CRM Analytics** → See which executives are performing and which lead sources are most productive
4. **Check Sales Analytics** → Review revenue trend and quotation status breakdown
5. **Examine the funnel and win/loss** → Understand pipeline distribution and conversion rate
6. **Check the leaderboard** → See which team members are top performers
7. **Review follow-up health** → Identify overdue and due-today action items
8. **Read system alerts** → Spot any urgent issues (unassigned leads, overdue follow-ups, pending approvals)
9. **Check CRM Health Score** → Get an overall system vitality rating
10. **Navigate to a module** → Click sidebar items or the "View All →" link on Recent Leads to take action

## Tips & Notes

- **The dashboard auto-loads on page visit.** There is no manual refresh button. To refresh the data, reload the page or change the date range filter.
- **The date range filter only affects sales analytics**, not SUKI KPIs. If you need time-filtered lead/quotation counts, use the Reports module instead.
- **All KPI numbers use count-up animation** — they animate from 0 to their final value on page load.
- **The dashboard is fully responsive** — on smaller screens, the multi-column grids collapse to fewer columns, and the charts adjust their dimensions.
- **Dark mode is supported** — all dashboard widgets adapt to the system's light/dark theme setting.
- **Currency display** follows the system's currency setting (e.g., ₹ for INR, $ for USD).
